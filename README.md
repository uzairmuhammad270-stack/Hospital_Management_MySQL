# Hospital Management System – MySQL

## Overview

A **Hospital Management System database** designed and implemented using **MySQL** to organize and manage hospital-related data and relationships.

## Database Tables

* **Hospitals** – Hospital information
* **Doctors** – Doctor details and hospital assignments
* **Patients** – Patient records
* **Appointments** – Patient-doctor appointment records
* **Departments** – Hospital departments
* **Medications** – Medication information
* **Prescriptions** – Patient prescriptions and medications
* **Rooms** – Hospital room and allocation details

## Project Work

* Designed a relational database structure
* Created and populated multiple interconnected tables
* Established relationships using **Primary Keys and Foreign Keys**
* Wrote SQL queries to retrieve, filter, join, and analyze hospital data
* Used **JOINs, aggregations, subqueries, and filtering** for data analysis

## Tools

**MySQL | SQL | Relational Database Design | Joins | Aggregations**

## Objective

To build a structured hospital database that enables efficient management and analysis of **hospitals, doctors, patients, appointments, departments, medications, prescriptions, and rooms**.
